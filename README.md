# Chain Ladder Loss Reserving

## What This Is
My first actuarial programming project. I used the chain ladder method to estimate IBNR (incurred but not reported reserves) — how much an insurance company needs to set aside for unpaid claims.

## What I Did
- Loaded a real loss triangle dataset (RAA) using the `chainladder` Python library
- Ran the classical chain ladder model to project ultimate losses
- Visualized loss development patterns with matplotlib

## Key Takeaway
Early accident years had stabilized, while recent years still require significant additional reserves — exactly why loss reserving matters for financial reporting.

## Tools
Python (pandas, matplotlib, chainladder) | Google Colab
